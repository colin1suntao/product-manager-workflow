# 个人记账应用产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称和定位
- **产品名称**： “简记” (SimpleLedger)
- **产品定位**： 一款面向个人及家庭用户的轻量级、智能化记账工具。旨在通过极简的操作流程，帮助用户轻松记录日常收支，并通过清晰的统计与报表，洞察消费习惯，实现个人财务的轻松管理。

### 1.2 解决的问题和目标用户
- **解决的问题**：
    1.  **财务不透明**： 用户不清楚自己的收入和支出流向，月末常感觉“钱不知道花哪了”。
    2.  **记账繁琐**： 传统记账方式（如手动记在本子上或复杂表格）步骤多、易放弃，难以坚持。
    3.  **缺乏洞察**： 仅有流水记录，无法从数据中获得有价值的消费分析和趋势洞察。
- **目标用户**： 有记账意识或希望开始记账的个人用户，特别是年轻上班族、学生及家庭主妇/主夫。

### 1.3 产品愿景和核心价值
- **产品愿景**： 成为最简单、最懂用户的个人财务助手，让记账像发朋友圈一样自然。
- **核心价值**：
    1.  **极速记录**： 3秒内完成一笔账目的记录。
    2.  **清晰洞察**： 自动生成易于理解的统计图表和月度报告。
    3.  **习惯养成**： 通过轻量交互和正向激励，帮助用户养成记账习惯。

## 2. 目标用户

### 2.1 用户画像
| 角色 | 特征 | 痛点 |
| :--- | :--- | :--- |
| **小李 - 上班族** | 25-35岁，有固定收入，消费渠道多样（外卖、网购、线下）。 | 工作忙，没时间详细记账；想控制消费但不知从何下手；需要了解每月固定开支占比。 |
| **小明 - 学生** | 18-24岁，生活费有限，消费集中在社交、学习、娱乐。 | 预算有限，容易超支；想了解钱花在哪些非必要项目上；需要简单易上手的工具。 |
| **王女士 - 家庭主妇** | 30-45岁，管理家庭日常开支，涉及多人、多类消费。 | 家庭开销繁杂，容易遗漏；需要清晰区分不同家庭成员或不同用途的开支；月底对账困难。 |

### 2.2 使用场景
- **场景一（快速记录）**： 小李在便利店买完咖啡，打开App，点击“记一笔”，选择“餐饮”分类，输入金额，保存，全程无需打字。
- **场景二（月末复盘）**： 月底，小明查看“月度报表”，发现“娱乐”支出占比高达40%，决定下月在此项上严格控制预算。
- **场景三（家庭对账）**： 王女士月末查看“分类统计”，将“子女教育”和“家庭日用”的支出截图分享给丈夫，共同回顾家庭财务状况。

## 3. 功能需求

### 3.1 功能模块清单（按优先级排列）
| 优先级 | 功能模块 | 简要说明 |
| :--- | :--- | :--- |
| **P0** | 核心记账 | 支持收入/支出的快速记录、编辑和删除。 |
| **P0** | 分类管理 | 提供预设分类，支持用户自定义分类。 |
| **P0** | 账户管理 | 支持管理多个资金账户（现金、银行卡、支付宝等）。 |
| **P1** | 数据统计 | 提供按日、周、月、年维度的收支汇总和分类占比图表。 |
| **P1** | 月度报表 | 自动生成并推送月度财务总结报告。 |
| **P2** | 多账本 | 支持创建独立账本（如“旅行账本”、“装修账本”）。 |
| **P2** | 预算设置 | 支持为分类设置月度预算，并提供超支提醒。 |
| **P2** | 数据导出 | 支持将数据导出为Excel或CSV格式。 |

### 3.2 功能详细描述

#### 3.2.1 核心记账 (P0)
- **功能说明**： 用户能够快速记录一笔收入或支出。
- **用户故事**：
    - 作为一个用户，我希望能快速记录一笔支出/收入，以便追踪我的财务状况。
- **验收标准**：
    1.  用户可通过首页显眼的“+”按钮开始记录。
    2.  记账界面默认为“支出”，可一键切换为“收入”。
    3.  必填字段：金额（数字键盘）、分类（从列表选择）。
    4.  选填字段：备注、账户（默认使用上次账户）、日期（默认为当前日期）。
    5.  输入金额后，点击“保存”即完成记录，并返回首页，首页数据实时更新。
    6.  支持对历史记录进行编辑和删除操作。
- **优先级**： P0

#### 3.2.2 分类管理 (P0)
- **功能说明**： 系统提供一套通用的收支分类体系，并允许用户自定义。
- **用户故事**：
    - 作为一个用户，我希望能用符合我习惯的类别来对账目进行分类，以便更清晰地分析。
- **验收标准**：
    1.  系统预设至少10个常用支出分类（如餐饮、交通、购物）和5个收入分类（如工资、奖金、利息）。
    2.  每个分类配有直观的图标。
    3.  用户可新增、编辑（修改名称/图标）、删除自定义分类。
    4.  系统预设分类不可删除，但可隐藏。
    5.  删除自定义分类时，若该分类下已有账目，需提示用户选择将这些账目迁移至哪个其他分类。
- **优先级**： P0

#### 3.2.3 账户管理 (P0)
- **功能说明**： 管理用户的资金账户，记录不同账户间的资金流动。
- **用户故事**：
    - 作为一个用户，我希望能管理我的现金、银行卡和电子钱包余额，以便知道钱放在哪里。
- **验收标准**：
    1.  系统默认提供“现金”账户。
    2.  用户可新增账户，需填写：账户名称、类型（现金/信用卡/储蓄卡/电子钱包）、初始余额。
    3.  记账时可选择资金流出/流入的账户。
    4.  当记录一笔支出时，所选账户的余额自动扣减；记录收入时，余额自动增加。
    5.  支持“转账”功能，记录资金在账户间的转移，并同时更新两个账户的余额。
    6.  账户列表页显示各账户当前余额。
- **优先级**： P0

#### 3.2.4 数据统计 (P1)
- **功能说明**： 以图表形式直观展示用户的收支情况。
- **用户故事**：
    - 作为一个用户，我希望一眼就能看清我这个月的钱主要花在了哪些地方，以及我的收入构成。
- **验收标准**：
    1.  提供“统计”页面，顶部可切换时间范围（本周/本月/本年）。
    2.  核心图表一：**收支总览**。显示选定时间范围内的总收入、总支出、结余。
    3.  核心图表二：**分类支出占比**。以饼图或环形图展示各支出分类的金额和占比。
    4.  核心图表三：**每日收支趋势**。以折线图展示选定时间范围内每天的收入和支出金额。
    5.  点击图表中的分类扇区或趋势点，可下钻查看该分类或该日的具体账目列表。
- **优先级**： P1

#### 3.2.5 月度报表 (P1)
- **功能说明**： 在每月初，自动生成上个月的综合财务报告。
- **用户故事**：
    - 作为一个用户，我希望每个月初都能收到一份简洁明了的上月财务总结，了解自己的财务状况。
- **验收标准**：
    1.  系统在每月1日自动生成上月的月度报表。
    2.  报表内容包括：月总收入、总支出、结余；支出TOP 5分类；与上月支出的对比（总额及主要分类变化）。
    3.  以卡片式或文章式布局呈现，图文结合，易于阅读。
    4.  提供“分享”功能，可将报表以图片形式保存或分享至社交平台。
    5.  用户可在“报表”历史列表中查看所有已生成的月度报表。
- **优先级**： P1
